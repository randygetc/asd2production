# PTO Agent — Learnings and Reusable Field Signals

Purpose: capture evidence-backed deployment learnings, not speculative design notes.

## Entry template
- ID / date
- Workflow/use case
- Observation
- Evidence / frequency
- Business impact
- Root cause / uncertainty
- Action taken
- Regression/eval added
- Reusable pattern or product/research field signal

## Initial hypotheses to validate (not learnings yet)
- Partial-day/time-zone language may require specialized temporal interpretation.
- Policy effective-date reasoning may benefit from deterministic temporal verification.
- Human escalation cost may dominate LLM cost and should be measured separately.

Move a hypothesis to a learning only after production/eval evidence supports it.
