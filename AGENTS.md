# Repository Agent Instructions

All coding agents working in this repository must follow `CLAUDE.md` and the authority hierarchy it defines.

Before material changes, read the relevant business/design artifacts under `docs/`, especially `docs/ADS.md`, accepted ADRs, `docs/TSD.md`, `docs/architecture.md`, `docs/conventions.md`, `docs/EVALS.md`, `docs/traceability.yaml`, and `docs/plan.md`.

Do not resolve business, authority, security, or architectural ambiguity by guessing. Record unresolved owner decisions under `docs/owner-decisions/` and stop the affected implementation path until the decision is made.
